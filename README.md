# Example generators

These ten files used to be built into the mod and shipped as the default
generator set. They are now plain user-script examples — the mod ships with
**no** generators of its own, and the player gets exactly what they put into
`autochisel/scripts/` (and nothing more).

To use any of them in-game:

1. Copy the desired `*.cs` file (or all of them) into your VS data folder:
   `%APPDATA%/VintagestoryData/autochisel/scripts/`
2. Open the model browser (default key `Z`) → **Generators** tab.
3. The generator now appears in the list. Adjust parameters → Generate & Load.

If you edit a script while the game is running, just close and re-open the
browser to pick up the changes (the folder is rescanned on each open).

These files are excluded from the main mod compilation via the `<Compile
Remove="examples\**\*.cs" />` rule in `Arkholl Chisel.csproj`, so they only
exist as reference/copy-paste material here in the source tree.

See `autochisel/scripts/README.txt` (auto-generated by the mod on first run)
for the full scripting reference, including the `AssetFolderName` mechanism
for generators that need their own image/data folder.
